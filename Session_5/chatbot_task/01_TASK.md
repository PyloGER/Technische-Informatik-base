# Task
## Englisch
1. Your task is to build the application and run it in a container setup. Therefore, fill in the missing code marked as `...` and make sure the application is running properly.
2. Identify 3 findings where the current application needs improvement and explain these to your group. Write an issue in github for each of the findings.
   An example is: 
   - Issue: "Currently I can not verify which information is used from the retrieval"
   - Possible Solution: "Display the retrieved chunks in the chat window.
3. Solve these findings and build an improved version of the chatbot.
   Use branches for the development

## Deutsch
1. Ihre Aufgabe besteht darin, die Anwendung zu erstellen und in einem Container-Setup auszuführen. Füllen Sie daher den fehlenden Code mit der Bezeichnung „...“ aus und stellen Sie sicher, dass die Anwendung ordnungsgemäß ausgeführt wird.
2. Identifizieren Sie 3 Erkenntnisse, bei denen die aktuelle Anwendung verbessert werden muss, und erklären Sie diese Ihrer Gruppe. Schreiben Sie für jedes der Ergebnisse ein Problem in GitHub.
   Ein Beispiel ist: 
   - Problem: „Derzeit kann ich nicht überprüfen, welche Informationen aus dem Abruf verwendet werden.“
   - Mögliche Lösung: „Zeigen Sie die abgerufenen Blöcke im Chatfenster an.
3. Lösen Sie diese Erkenntnisse und erstellen Sie eine verbesserte Version des Chatbots.
   Nutzen Sie Zweige für die Entwicklung
